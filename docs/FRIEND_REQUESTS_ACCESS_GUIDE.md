```

  ├─→ Notifications Tab
  │     │

  │           │

  │                 │

  │                 └─→ [View Profile] → Full user profile
  │

          │
          └─→ (If they sent YOU a request)
                └─→ [Accept] [Decline] buttons visible

```

## 🎯 Where to Find Your Friend Requests

### Primary Method: Notifications Screen
1. Open the app
2. Tap **Notifications** (🔔) tab at the bottom
3. Look for **👥** icon in the top-right corner
4. **Red badge** shows count (if you have pending requests)
5. Tap the icon → **Friend Requests Screen** opens

### Secondary Method: User Profiles
- Navigate to the profile of someone who sent you a request
- You'll automatically see **Accept** and **Decline** buttons
- No need to go to Friend Requests screen

## 🎨 Visual Indicators

### Badge States
| State | Badge | Meaning |
|-------|-------|---------|
| No requests | No badge | All clear! |
| 1 request | `1` | One pending |
| 5 requests | `5` | Five pending |
| 10+ requests | `9+` | Nine or more |

### Button Colors
| Button | Color | Action |
|--------|-------|--------|
| Accept | 🟢 Green | Become friends |
| Decline | 🔴 Red | Reject request |

## ⚡ Quick Actions

### To Accept a Friend Request:
1. Tap **Notifications** tab
2. Tap **👥** icon
3. Find the request
4. Tap green **[Accept]** button
5. ✓ Done! You're now friends

### To Decline a Friend Request:
1. Tap **Notifications** tab
2. Tap **👥** icon
3. Find the request
4. Tap red **[Decline]** button
5. Confirm in dialog
6. ✓ Request removed

### To View Someone's Profile from Request:
1. Open Friend Requests screen
2. Tap **🔗** icon next to their name
3. OR tap anywhere on their name/avatar
4. ✓ Profile opens

## 🔄 Auto-Refresh

The Friend Requests screen automatically refreshes after:
- ✓ Accepting a request
- ✓ Declining a request
- ✓ Pulling down to refresh manually

The badge count updates instantly!

## 📊 Empty State

If you have no pending requests, you'll see:
```
        👥
        
  No Friend Requests
  
  You don't have any
  pending friend requests
```

## 🎯 Pro Tips

1. **Badge as Indicator**: Always check the Notifications tab for the red badge
2. **Quick Accept**: Accept directly from user profiles without opening requests screen
3. **View Profile First**: Tap 🔗 to see someone's full profile before accepting
4. **Decline with Care**: Declining shows a confirmation dialog - no accidental rejections!
5. **Pull to Refresh**: Swipe down anytime to check for new requests

## 🆘 Troubleshooting

### "I don't see any requests"
- Check if the badge shows a number
- Pull down to refresh the list
- Make sure someone actually sent you a request

### "Badge shows count but list is empty"
- Pull down to refresh
- Check your internet connection
- Try going back and reopening the screen

### "Accept button not working"
- Wait for any loading indicators to finish
- Check internet connection
- Try again in a few seconds
